Ввод данных: в main вводится число n через консоль (с помощью Scanner). 
Программа проверяет, что n>0, и выводит ошибку, если условие не выполнено.
Расчёт суммы: метод computeSum(int n) выполняет вычисления:
проверяет, что n≥0 (иначе выбрасывает исключение);
инициализирует переменные: sum (итоговая сумма, начинается с 0,0), factorial (факториал текущего числа, начинается с 1,0) и sign (знак слагаемого, начинается с −1);
в цикле от 1 до n:
обновляет факториал
добавляет к сумме слагаемое 
меняет знак на противоположный (sign = -sign) для следующего слагаемого.
Вывод результата: программа выводит вычисленную сумму ряда.
